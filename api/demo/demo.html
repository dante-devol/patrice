Try Patrice in your browser

This is a demo of Patrice, a task board for volunteer teams. There is no server behind this page: the real Patrice API and its PostgreSQL database are compiled to WebAssembly and run locally, inside your browser.

  • The first start downloads about 12 MB and loads a sample organisation with tasks, divisions and people.
  • Everything you do stays in this browser. Nothing is sent anywhere, and other visitors don't see your changes.
  • Email, Discord and file uploads are switched off in the demo.
  • You'll log in as admin@example.com with the password correct horse battery.
